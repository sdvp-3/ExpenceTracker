# Expense Tracker

Daromad, xarajat va balansni ko‘rsatish uchun mo‘ljallangan oddiy Expense Tracker interfeysi. Loyiha HTML va CSS yordamida tayyorlangan; hozircha sahifadagi qiymatlar namunaviy, tranzaksiyalarni hisoblash yoki saqlash funksiyasi mavjud emas.

## Loyihani ishga tushirish

1. Repozitoriyni kompyuteringizga yuklab oling yoki klonlang.
2. `index.html` faylini brauzerda oching.

Loyiha statik fayllardan iborat, shu sababli alohida paket o‘rnatish yoki build buyrug‘i talab qilinmaydi.

## Loyihaning tuzilishi

```text
.
├── index.html       # Sahifaning HTML tuzilishi
├── index.css        # Ko‘rinish va responsive Grid joylashuvi
├── index.js         # JavaScript uchun fayl (hozircha bo‘sh)
└── pic/
    ├── expence.png  # Sahifadagi logo
    └── icon.png     # Qo‘shimcha ikonka
```

## Interfeys bo‘limlari

- Umumiy balans, daromad va xarajat kartalari
- Yangi tranzaksiya, tranzaksiyalar ro‘yxati va kategoriyalar uchun panellar
- Katta ekranda Grid ustunlari, kichik ekranlarda esa bitta ustunli joylashuv

## Texnologiyalar

- HTML5
- CSS3 (CSS Grid va media query)
- JavaScript (kelajakdagi funksiyalar uchun)
